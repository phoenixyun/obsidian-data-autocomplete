Retrieval priority: EXACT → ALIAS → PARTIAL → SEMANTIC_CANDIDATE → NO_RESULT.
Structured hits always win over semantic (AD-21); semantic fallback is a fully local hash-vector + cosine (256-dim, no model, no network), accepting only strong approximations ≥ 0.5.
